Unit 2 · 5 min read → 40-sec card

What is AI?

  • Modern AI = machine-learning models trained on huge data → interpret input · reason · respond · predict
  • Generative AI: LLMs create original output from natural-language prompts (text, images, code)
  • Agents = generative AI put to work: LLM + instructions + tools → automates tasks semi/fully autonomously
  • NLP: statistical + task-specific models still best for classification · sentiment · summarization
  • Speech: recognize + synthesize · handles noise, interruptions, accents · transcription + read-aloud
  • Vision: interpret images/video/live camera · multimodal models also generate visuals
  • Information extraction: pull key facts from docs, forms, images, recordings
Exam angleScenario → capability matching. Find the verb in the question: create / act / read / hear / see / extract.

Unit 3 · 5 min read → 40-sec card

Microsoft Foundry

  • Foundry = Azure's AI dev platform · recommended for all but the simplest solutions · portal + SDK
  • Project = your workspace (connections, data, code) · belongs to exactly 1 Foundry resource
  • Resource hosts many projects (one is default) · provides compute, storage, AI tools
  • Project assets = M·A·T·K: Models · Agents · Tools · Knowledge
  • Models: reach deployments via 2 endpoints · project endpoint (Foundry APIs) · Azure OpenAI endpoint (OpenAI SDKs)
  • Agents: built + consumed via Foundry Agent Service · tools connect over MCP
  • Foundry IQ: one central MCP knowledge connection → grounding made simple
  • Portal = find/compare/deploy/test models, build agents, manage access + keys · SDK = automation, CI/CD
Exam angle"Which portal manages project assets?" → Foundry portal (not Azure portal). "Classic" = older hub-based projects.

Path 1 · GenAI apps

  • Deploy: Global Standard default · PTU predictable · Batch −50% ≤24h · Data Zone residency
  • Responses API = stateful (previous_response_id) · ChatCompletions = resend history
  • Foundry SDK = agents/evals/tracing · OpenAI SDK = portable inference
  • Tools: code_interpreter · web_search · file_search · function (your code runs it)
  • Optimize ladder: prompts → RAG (hybrid search!) → fine-tune (LoRA: SFT · RFT · DPO)
  • RAI: Map→Measure→Mitigate→Manage · layers Model→Safety→SysMsg→UX · filters 4 sev × 5 cat · prompt shields = jailbreaks

Path 2 · AI agents

  • Declarative (prompt / workflow YAML) vs hosted (containers) · deploy = project, publish = Agent Application (Entra-only, reassign RBAC!)
  • Custom tools: functions · Azure Functions · OpenAPI (anon/key/MI) · Logic Apps
  • MCP: MCPTool(label,url) · require_approval always default · allowed_tools
  • Foundry IQ: 6 sources · SP Remote live+permissions vs Indexed fast+powerful
  • Workflows: If/Else · For Each · Power Fx · versions immutable
  • Agent Framework = SK + AutoGen · service-side history = Foundry · approval_mode
  • 5 orchestrations: concurrent · sequential · handoff · group chat · Magentic (ledger) · A2A = agent↔agent, Agent Card at /.well-known

Path 3 · Language

  • Azure Language now: detect · NER · PII redaction (sentiment/summary/key-phrases deprecated) · 5,120 chars/doc, 1,000 docs
  • Speech chain: SpeechConfig → AudioConfig → Recognizer/Synthesizer · Reason: RecognizedSpeech / NoMatch / Canceled · SSML = style, phonemes, prosody
  • GenAI speech models: -transcribe · -tts · -diarize = speakers
  • MCP: Language server = 4 text tools · Speech server needs blob + SAS · phrase hints boost accuracy
  • Voice Live: WebSocket speech-to-speech · barge-in = stop playback on speech-started · CS User + ai.azure.com/.default
  • Translator: to_language list · omit from = auto-detect · transliterate = scripts · event-based synth = 1:1 only

Path 4 · Vision & extraction

  • Vision chat: multi-part message, image = URL or base64 data URL · image gen = gpt-image-1 · FLUX
  • Sora 2: 4/8/12 s · async poll · 2 jobs · 24 h window · ref image exact res, no faces · remix by video_id
  • Content Understanding: schema → extract/classify/generate · confidence ≥0.9 auto, <0.7 manual · needs GPT-4.1 + mini + embedding deployments · :analyze vs analyzeBinary
  • Doc Intelligence: read/layout · template fixed vs neural varied · composed routes · 5-6 samples min
  • AI Search: indexer → skillset → index · attributes: searchable/filterable/facetable/sortable · $filter case-sensitive · knowledge store projections (tables/JSON/images)
