# AI-103 Visual Prep

A visual-first study app for **Exam AI-103: Developing AI Apps and Agents on Azure** (Microsoft Certified: Azure AI Apps and Agents Developer Associate).

**Use it here → https://anthony-websitesoft.github.io/ai103-visual-prep/**

## What's inside

- **Map** · the whole exam world on one screen: Microsoft Foundry architecture, the 5 AI capabilities, decision shortcuts, and a 2026 old-name → new-name decoder
- **Topics** · all 30 course modules across 4 learning paths, each compressed to shorthand bullets + an "exam angle" callout, with source links
- **Flashcards** · 206 cards in per-path decks with got-it/again tracking
- **Quiz** · 136 exam-style questions with instant explanations, drillable by scope (25-question mix, per path, or everything)
- **Exam** · domain weights with expandable skills, plus a 30-module roadmap checklist
- **Cram sheet** · printable one-page-per-path summaries

Progress (cards known, quiz best, modules done) is stored in your browser only: nothing is sent anywhere, and each person gets their own tracking. To move progress between devices, use the Export and Import progress buttons in the footer.

## Files

- `index.html`: the app (standalone, no build, no dependencies, open it locally or host it anywhere)
- `app.html`: the same content as a body-only fragment (source for other hosting)
